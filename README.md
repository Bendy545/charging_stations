# Charging analysis 

This project covers an in depth analysis of charging stations on a selected location.  

## Addressed problems

- reactive power  
- losses (approximately 15%)

## Main goals

- Analyze those problems
- Find solutions if possible
- Confirm if the results are correct

# Architecture

- The project is an webpage that shows results through graphs and calculations.
- Two main components:
    - Backend (Python)
    - Frontend (React)
 
- The project also uses a MySQL database for saving data.
